## CodeAlpha Calculator
This project is a responsive and interactive Calculator built using:

HTML

CSS

JavaScript

It performs basic arithmetic operations and provides real-time result display.

## Features
Addition (+)

Subtraction (−)

Multiplication (×)

Division (÷)

Clear (C) button

Real-time display screen

Responsive design

Clean and modern UI

Keyboard support (Bonus Feature)

## Project Structure
CodeAlpha_Calculator/

│── index.html

│── style.css

│── script.js

│── README.md

## How to Run
Download or clone the repository

Open index.html in your browser

OR

Use Live Server in VS Code
